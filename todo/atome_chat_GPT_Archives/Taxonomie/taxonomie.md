# Taxonomie atome

Ce dossier contient la **source de travail partagée** pour la taxonomie des menus, outils et contextes d’atome/eVe.

## Tableur maître

[Ouvrir `atome_taxonomie_menus_v02.xlsx`](./atome_taxonomie_menus_v02.xlsx)

La version `v02` est une **proposition de travail** : les lignes marquées `À valider` doivent être arbitrées avant d’être considérées comme définitives.

## Principes retenus dans v02

- ne jamais forcer une dimension là où elle n’a pas de sens : utiliser `N/A` ;
- le **Dashboard est hors projet** : il n’est donc pas assimilé au mode `Consultation` ;
- l’ordre d’évaluation est : **scope → mode Travail → sélection → type/capacités → vue → profil → permissions/périphériques** ;
- le **Flower** conserve quatre positions persistantes et quatre pétales contextuels ;
- le **menu principal** est proposé en structure hybride : ancres stables + outils centraux contextuels ;
- le **menu contextuel** est entièrement déterminé par la sélection et n’a pas de partie fixe ;
- `Transport` et `Record` ne sont présents dans l’atelier que si la temporalité ou la capture les justifient ;
- `Naturel / Liste / Matrice` modifie la représentation des atomes/molécules, pas la structure des tools.
