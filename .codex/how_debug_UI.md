# Validation visuelle eVe

La procédure canonique est [atome/documentations/how_debug_UI.md](../atome/documentations/how_debug_UI.md).

Sa lecture complète et son application sont obligatoires dès qu'une demande mentionne une vérification UI, une vérification visuelle, un test d'interaction, un problème de clic, de geste, de hit-test, d'overlay ou de rendu eVe. Une validation ne peut pas être déclarée réussie sur la seule base de tests internes, d'état JavaScript ou de records : elle doit respecter les gestes réels, les diagnostics et la preuve par pixels décrits dans ce document.

Ce fichier est uniquement un lien d'entrée. La procédure sous `atome/documentations/` reste l'unique source de vérité et ne doit pas être recopiée ici.
